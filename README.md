# Surendra Bhujel – Portfolio

Professional portfolio website built with **Next.js**, **Tailwind CSS**, and **Framer Motion**.

## Features

- Modern dark theme with smooth animations
- Fully responsive (mobile-first)
- Sections: Hero, About, Skills, Projects, Education & Certifications, Contact
- Project cards with live demo & GitHub links
- Sticky navigation with active section highlighting

## Tech Stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React (icons)

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Customize

- Update the email address in `src/app/page.tsx` (currently a placeholder)
- Add your real LinkedIn or other social links if desired
- Replace project screenshots or add images in the `public/` folder if you want visual previews

## Deploy

Easiest way is to deploy on [Vercel](https://vercel.com):

1. Push this repo to GitHub
2. Import the project on Vercel
3. Deploy

Or use Render / Netlify – same process.
